    **A. telegram_bot.py -- Add traffic digest section (ANLY-03):**

    1. Add a new function `get_traffic_digest() -> list[str]` that:
       - For each locale in ["en", "it", "es"]:
         - Calls `strapi.find_all_pages(ct, locale=locale, fields=["title", "slug", "traffic_score_7d"], sort="traffic_score_7d:desc", page_size=500)` for each ct in ["blog-posts", "reviews", "recipes", "tutorials"]
         - Merges all results into one list, sorts by traffic_score_7d descending
         - Filters out items with traffic_score_7d == 0 or None
         - Takes top 5 and bottom 5 (bottom = last 5 of non-zero items)
         - Formats as HTML lines:
           ```
           <b>TRAFFICO {LOCALE} (7gg)</b>
           Top 5:
             {visits}v - {title}
             ...
           Bottom 5:
             {visits}v - {title}
             ...
           ```
       - Returns all lines as a list of strings

    2. In the `daily_report()` async function, insert the traffic digest AFTER the "TRAFFICO" (Umami stats) section and BEFORE the "CONTENUTI" section:
       ```python
       # Digest traffico per contenuto
       try:
           traffic_lines = get_traffic_digest()
           if traffic_lines:
               lines.extend(traffic_lines)
               lines.append("")
       except Exception as e:
           lines.append(f"<i>Traffic digest non disponibile: {e}</i>")
           lines.append("")
       ```

           - Collects items with traffic_score_7d > 0

       - Returns formatted string with top 10 performers and bottom 10 performers:
