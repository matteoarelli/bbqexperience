# Plan 10.1-01 — Cloudflare prerequisites (orange-cloud + Transformations + Sources)

Evidence log della configurazione dashboard Cloudflare eseguita manualmente da Matteo + probe automatizzati di verifica. Questo artefatto attesta git-side il cambio di stato lato CF (threat T-10.1-04 mitigato).

## Probe A — orange-cloud

Verifica che il traffico verso `bbq-experience.com` passi dall'edge Cloudflare (non più direttamente da Caddy su Hetzner).

**Comando:**
```bash
curl -sI https://bbq-experience.com/en/ | grep -iE "^(cf-ray|server|HTTP/):"
```

**Output:**
```
Server: cloudflare
CF-RAY: 9ed3d3470b52edbc-MXP
```

**Esito:** PASS — `cf-ray` e `server: cloudflare` presenti. Zone orange-cloud confermato.

## Probe B — transform endpoint

Verifica che `Images → Transformations` sia abilitato e che `cms.bbq-experience.com` sia nella Sources allowlist (asset reale ridotto + header edge).

**Comando:**
```bash
curl -sI "https://bbq-experience.com/cdn-cgi/image/width=320,quality=75,format=auto/https://cms.bbq-experience.com/uploads/oklahoma_joes_new_offset_smoker_lineup_5eed5de129.jpg" \
  | grep -iE "^(HTTP/|content-type|cf-cache-status|cf-ray|content-length):"
```

**Output:**
```
Content-Type: image/jpeg
Content-Length: 12242
CF-Ray: 9ed3d35708e1ed97-MXP
CF-Cache-Status: MISS
```

**Esito:** PASS
- `Content-Type: image/jpeg` — formato immagine (AVIF/WebP non negoziati perché curl non manda header `Accept: image/avif,image/webp`; fallback JPEG è comportamento atteso per UA senza negoziazione)
- `Content-Length: 12242` bytes (~12 KB) — contro ~111 KB originali = **-89% payload**, ben sotto la soglia acceptance di 60 KB
- `CF-Ray` presente → richiesta processata dall'edge
- `CF-Cache-Status: MISS` → prima richiesta, sarà HIT alla successiva

## Probe C — SSRF guard

Verifica che un'origine NON in allowlist (`example.com`) venga rifiutata dall'edge → Sources allowlist è subdomain-esatto (mitigazione threat T-10.1-01).

**Comando:**
```bash
curl -sI "https://bbq-experience.com/cdn-cgi/image/width=320,format=auto/https://example.com/robots.txt" | head -5
```

**Output:**
```
HTTP/1.1 403 Forbidden
Date: Thu, 16 Apr 2026 14:19:33 GMT
Content-Type: text/plain;charset=utf-8
Content-Length: 65
Connection: keep-alive
```

**Esito:** PASS — `HTTP/1.1 403 Forbidden` → 4xx come atteso. Nessun SSRF verso `example.com`.
