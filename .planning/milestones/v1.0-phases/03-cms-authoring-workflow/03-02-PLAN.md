**1. Update `web/astro.config.mjs`:**
Change `output: 'static'` to `output: 'hybrid'`. This makes all pages static by default but allows specific pages/endpoints to opt into SSR with `export const prerender = false`. Add `@astrojs/node` adapter for SSR:
- Install: `npm install @astrojs/node`
- Add to config: `import node from '@astrojs/node';` and `adapter: node({ mode: 'standalone' })` in defineConfig.

**2. Create `web/src/lib/preview.ts`:**
Export constants and helpers:
- `PREVIEW_COOKIE_NAME = 'bbq_preview'` 
- `PREVIEW_SECRET` — read from `import.meta.env.PREVIEW_SECRET`
- `isPreviewMode(cookies: AstroCookies): boolean` — returns true if the preview cookie value matches PREVIEW_SECRET
- `getContentStatus(cookies: AstroCookies): 'published' | 'draft'` — returns 'draft' if preview mode, 'published' otherwise

Import `AstroCookies` type from `'astro'`.

**3. Create `web/src/pages/api/preview.ts`:**
SSR endpoint (`export const prerender = false`).

`GET` handler:
- Read `secret` and `slug` and `type` (content type, defaults to 'reviews') and `locale` (defaults to 'en') from `Astro.url.searchParams`
- If `secret` does not match `PREVIEW_SECRET`, return 401 JSON response `{ error: 'Invalid preview secret' }`
- If `slug` is missing, return 400 JSON response `{ error: 'Missing slug parameter' }`
- Set cookie `bbq_preview` with value = PREVIEW_SECRET, httpOnly, path '/', sameSite 'lax', maxAge 3600 (1 hour expiry)
- Redirect to `/${locale}/${type}/${slug}/` (e.g., `/en/reviews/weber-summit/`)

Also export a `DELETE` handler for `/api/preview` that clears the cookie and redirects to homepage.

**4. Create `web/src/middleware.ts`:**
Astro middleware using `defineMiddleware` from `'astro:middleware'`.
- Read the preview cookie from `context.cookies`
- If preview cookie matches PREVIEW_SECRET, set `context.locals.isPreview = true`
- Otherwise set `context.locals.isPreview = false`
- Call `next()`

Also update the `Locals` type declaration. Create or update `web/src/env.d.ts` to add:
```typescript
declare namespace App {
  interface Locals {
    isPreview: boolean;
  }
}
```

**5. Add to `.env.example`:**
Add `PREVIEW_SECRET=change-me-to-a-random-string` line.

**Create `web/src/pages/en/reviews/[slug].astro`:**

Set `export const prerender = false` (SSR — needed for preview mode to work with draft status). In the frontmatter:

1. Import `fetchBySlug` from `@lib/strapi`
2. Import `StrapiReview` from `@lib/types`
3. Import `getStrapiMediaURL` from `@lib/media`
4. Import `getContentStatus` from `@lib/preview`
5. Import `BaseLayout` from `@layouts/BaseLayout.astro`
6. Get `slug` from `Astro.params`
7. Get content status: `const status = getContentStatus(Astro.cookies)`
8. Fetch review: `const review = await fetchBySlug<StrapiReview>('reviews', slug!, { locale: 'en', populate: '*', status })`
9. If review is null, return `Astro.redirect('/en/')` (404 fallback)

In the template:
- Use BaseLayout with `title={review.title}`, `description={review.excerpt || ''}`, `locale="en"`
- Display a preview banner if `Astro.locals.isPreview`: a yellow/amber bar at top saying "PREVIEW MODE — This content is not published" with a link to `/api/preview?action=exit` to exit preview
- Render: `<h1>{review.title}</h1>`
- Render excerpt in a `<p>` tag
- Render `review.editorial_content` using `set:html` (rich text from Strapi)
- Render score_overall in a simple `<div>` with the number
- Render verdict in a `<blockquote>`
- If review has gallery, render first image using `getStrapiMediaURL(review.gallery?.[0])`

Since `prerender = false`, there is no `getStaticPaths`. The page is fully SSR. This is correct for preview mode — it handles both published and draft content via the status param. Phase 4 will optimize with static generation for published content.
