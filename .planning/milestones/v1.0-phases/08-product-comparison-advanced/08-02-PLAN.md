    1. Create FlameGauge.svelte — a Svelte 5 component rendering the overall score as an animated SVG radial gauge with flame theming:
       - Props (using $props rune): `score: number` (0-10), `size: number = 160`, `label: string = 'Overall Score'`
       - SVG specs:
         - viewBox: `0 0 {size} {size}`
         - Center: `cx={size/2}`, `cy={size/2}`
         - Radius: `r = (size - 16) / 2` (8px padding for stroke)
         - Background circle: `stroke="var(--color-bg-tertiary)"`, `stroke-width="10"`, `fill="none"`
         - Progress circle: `stroke-width="10"`, `fill="none"`, `stroke-linecap="round"`, `transform="rotate(-90 {cx} {cy})"` (start from top)
         - Circumference: `const circumference = 2 * Math.PI * r`
         - stroke-dasharray: `{circumference}`
         - stroke-dashoffset: starts at `{circumference}` (empty), animates to `{circumference * (1 - score / 10)}`
         - Stroke color: use a gradient — define `<defs><linearGradient id="flame-grad" x1="0" y1="0" x2="1" y2="1"><stop offset="0%" stop-color="var(--color-accent-ember)"/><stop offset="50%" stop-color="var(--color-accent-fire)"/><stop offset="100%" stop-color="var(--color-accent-amber)"/></linearGradient></defs>`, then `stroke="url(#flame-grad)"`
       - Outer glow: Add a subtle `filter: drop-shadow(0 0 8px rgba(249,115,22,0.4))` on the progress circle via CSS
       - Center text: score number in `font-family: var(--font-heading)`, `font-size: {size * 0.28}px`, `fill: var(--color-accent-amber)`, below it "/10" in `font-size: {size * 0.12}px`, `fill: var(--color-text-muted)`
       - Label below SVG: `<span>` with label text in `font-family: var(--font-heading)`, uppercase, `color: var(--color-text-muted)`, `font-size: var(--text-sm)`
       - GSAP animation in `onMount`:
         ```js
         import { gsap } from 'gsap';
         import { ScrollTrigger } from 'gsap/ScrollTrigger';
         gsap.registerPlugin(ScrollTrigger);

         onMount(() => {
           const circle = document.getElementById(`flame-progress-${uniqueId}`);
           gsap.fromTo(circle,
             { attr: { 'stroke-dashoffset': circumference } },
             {
               attr: { 'stroke-dashoffset': circumference * (1 - score / 10) },
               duration: 1.5,
               ease: 'power3.out',
               scrollTrigger: {
                 trigger: circle,
                 start: 'top 85%',
                 toggleActions: 'play none none none',
               },
             }
           );
         });
         ```
       - Generate unique ID with `const uniqueId = Math.random().toString(36).slice(2, 9)` to avoid SVG ID collisions when multiple gauges exist
