    1. Create ProductSelector.svelte — Svelte 5 component for selecting products to compare:
       - Props: `strapiUrl: string`, `locale: string`, `selectedIds: string[]` (documentIds), `maxProducts: number = 5`, `labels: Record<string, string>`
       - Events: dispatch `select` with documentId, dispatch `remove` with documentId
       - Internal state:
         - `let query = $state('')` — search input text
         - `let results = $state<Array<{documentId: string, title: string, productName: string, score: number}>>([])` — search results
         - `let isSearching = $state(false)`
       - Search logic: on input (debounced 300ms via setTimeout), fetch from Strapi REST API:
         ```
         fetch(`${strapiUrl}/api/reviews?filters[title][$containsi]=${query}&populate=product&locale=${locale}&pagination[pageSize]=10&status=published`)
         ```
         Map results to `{documentId, title, productName: data.product?.name, score: data.score_overall}`
       - UI layout:
         - Search input: `<input type="text" placeholder="{labels.searchPlaceholder}"` with styles: `bg-[var(--color-bg-tertiary)]`, `border: 1px solid var(--color-border-default)`, `rounded-[var(--radius-md)]`, `px-4 py-3`, `w-full`, `color: var(--color-text-primary)`, `font-family: var(--font-body)`
         - Results dropdown (shown when results.length > 0 and query.length >= 2): absolute positioned below input, `bg-[var(--color-bg-elevated)]`, `border: 1px solid var(--color-border-default)`, `rounded-[var(--radius-md)]`, `shadow-lg`, max-height 300px overflow-y-auto
         - Each result item: flex row with product name, score badge, "Add" button. Disable if already in selectedIds or selectedIds.length >= maxProducts
         - Selected products shown as pill chips below search: flex wrap, each pill has product name + "x" remove button. Pill style: `bg-[var(--color-bg-tertiary)]`, `rounded-[var(--radius-full)]`, `px-3 py-1`, `text-sm`

    3. Create ComparisonTool.svelte — root orchestrator:
       - Props: `strapiUrl: string`, `locale: string`, `labels: Record<string, string>`, `initialIds: string[]`
       - State:
         - `let selectedIds = $state<string[]>([])` — initialized from `initialIds` prop
         - `let reviews = $state<ComparisonReview[]>([])`
         - `let isLoading = $state(false)`
       - URL sync ($effect):
         - On selectedIds change, update `window.history.replaceState` with `?ids={selectedIds.join(',')}`
         - On mount, read `new URLSearchParams(window.location.search).get('ids')` and set selectedIds if present (this overrides initialIds)
       - Data fetching ($effect):
         - When selectedIds changes and has >= 2 items, fetch each review:
           ```
           const promises = selectedIds.map(id =>
             fetch(`${strapiUrl}/api/reviews/${id}?populate=product&locale=${locale}&status=published`)
               .then(r => r.json())
               .then(json => json.data)
           );
           reviews = await Promise.all(promises);
           ```
         - Show loading spinner during fetch
       - Layout:
         - Top: ProductSelector (pass strapiUrl, locale, selectedIds, labels)
         - Middle: count indicator "{N} of 5 products selected" with `color: var(--color-text-muted)`
         - Bottom: ComparisonTable (shown only when reviews.length >= 2), else show empty state message: "Select at least 2 products to compare"
         - Share button: when reviews.length >= 2, show a "Copy comparison link" button that copies current URL to clipboard
       - Handle ProductSelector events: on `select` add to selectedIds (if < 5), on `remove` filter out from selectedIds
