    - Handle empty state: show "No articles found" message.
    - Add data-animate to the grid for scroll animation.

    **Tutorial detail pages** ([slug].astro for en/it/es):
    - Use `export const prerender = false` (SSR for preview support, same pattern as review pages).

    - Breadcrumbs: Home > Tutorials > {title}.
