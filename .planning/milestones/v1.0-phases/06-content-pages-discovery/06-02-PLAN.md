  <action>
    **ReadingProgress.svelte** — A Svelte 5 component (use runes: `$state`, `$effect`, `$derived`). Props: `locale: string`. Behavior:
    - On mount, find all `h2[id]` elements in the page (these are section headings in ContentLayout).
    - Track scroll position with a `scroll` event listener on `window`.
    - Calculate reading progress as percentage: `scrollY / (documentHeight - windowHeight)`.
    - Render a fixed top bar (below header, `top: 4rem` on mobile, `top: 5rem` on lg) showing:
      - A thin progress bar (3px height, fire gradient from --color-accent-fire to --color-accent-amber, width = progress%).
      - A section navigation row below the bar: clickable section names (from h2 text content), highlight current section. Use IntersectionObserver on h2 elements to detect active section.
    - Only show when user has scrolled past 100px (fade in with CSS transition).
    - Hide completely when progress is 100% (user reached bottom).
    - Use `client:idle` directive when embedding in Astro pages.
    - Style with inline CSS using the design tokens as hardcoded values (Svelte components cannot access Astro CSS custom properties directly, so use the hex values: fire=#f97316, amber=#f59e0b, bg=#0D0D0D, text-primary=#F5F5F5, text-muted=#737373).

    **SearchDialog.svelte** — A Svelte 5 component. Props: `locale: string`, `translations: Record<string, string>` (pass subset: searchPlaceholder, noArticles, etc.). Behavior:
    - Renders a search trigger button (magnifying glass icon + "Search" text from translations).
    - On click, opens a modal dialog (centered overlay with dark backdrop).
    - Input field at top, auto-focused.
    - Content type filter buttons below input: All, Reviews, Recipes, Tutorials, Blog. Active filter highlighted with fire accent.
    - Results area below filters: show results as a list (title, excerpt snippet with highlighted matches, content type badge, URL).
    - Pagefind integration:
      - Lazy-load Pagefind: `const pagefind = await import('/pagefind/pagefind.js')` on first search.
      - Call `pagefind.search(query)` on input (debounce 300ms).
      - For each result, call `await result.data()` to get `{ url, title, excerpt, meta }`.
      - Filter client-side by content type using URL path patterns: `/tutorials/` or `/guide/` or `/tutoriales/` = tutorial, etc.
    - Close on Escape key or backdrop click.
    - Style: dark theme matching site (bg=#1A1A1A, border=#333, text=#F5F5F5).
    - Use `client:idle` directive when embedding in Astro pages.
    - Add `data-pagefind-body` attribute guidance in a code comment: remind executor that content pages need `data-pagefind-body` on their main content area for Pagefind indexing.
