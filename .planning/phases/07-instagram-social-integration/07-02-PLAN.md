  <action>
    read_first:
    - web/src/components/review/PhotoGallery.astro (reference for inline script pattern with data attributes)

    **LiteYouTube.astro** — YouTube facade embed (loads iframe only on user click):
    - Props: `videoId: string`, `title: string`
    - Render a div with:
      - Background image: `https://i.ytimg.com/vi/${videoId}/hqdefault.jpg` (YouTube thumbnail)
      - Play button overlay: red circle (#FF0000) with white triangle SVG, centered
      - aria-label: "Play: {title}"
    - Inline `<script>` tag: on click of `[data-lite-youtube]`, replace the div innerHTML with an iframe: `https://www.youtube-nocookie.com/embed/${videoId}?autoplay=1` (privacy-enhanced mode)
    - The iframe gets: width="100%", height="100%", allow="autoplay; encrypted-media", allowfullscreen, frameborder="0"
    - Container style: aspect-ratio 16/9, border-radius var(--radius-lg), overflow hidden, cursor pointer, position relative, background-size cover, background-center
    - After click, cursor becomes default and play button disappears (iframe replaces content)

    **LiteInstagramEmbed.astro** — Instagram post facade embed:
    - Props: `postUrl: string` (full Instagram permalink like https://www.instagram.com/p/ABC123/)
    - Render a div with:
      - Instagram gradient border (bottom edge: linear-gradient of IG brand colors)
      - Placeholder content: Instagram icon SVG + "View on Instagram" text + the post URL truncated
      - aria-label: "View Instagram post"
    - Inline `<script>` tag: on click of `[data-lite-instagram]`, replace content with Instagram oEmbed iframe: `${postUrl}embed/` in an iframe
    - The iframe gets: width="100%", height="480", frameborder="0", scrolling="no"
    - Container style: max-width 540px (Instagram embed standard), margin 0 auto, background var(--color-bg-secondary), border var(--color-border-subtle), border-radius var(--radius-lg), overflow hidden, cursor pointer
    - After click, set min-height to 480px to prevent layout shift while iframe loads

    These components are designed for authors to use in editorial_content and recipe editorial_intro markdown. They can be included via Astro components in custom content sections when building out richer article templates. For now, they exist as standalone components ready for use.
