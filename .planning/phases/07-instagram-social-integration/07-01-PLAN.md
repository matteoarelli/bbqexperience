    **InstagramCard.astro** — Single IG post card component:
    - Props: `post: StrapiInstagramPost & StrapiEntity`, `locale: Locale`
    - Render cached_image (via getStrapiMediaURL) with fallback to media_url for display
    - Show VIDEO icon overlay if media_type is 'VIDEO' or 'CAROUSEL_ALBUM' (carousel icon for albums)
    - Caption truncated to 2 lines with CSS line-clamp
    - Entire card is a link to post.permalink (opens in new tab with rel="noopener noreferrer")
    - Style: Dark card (var(--color-bg-secondary)), border (var(--color-border-subtle)), rounded corners (var(--radius-lg)), hover lift effect (translateY(-4px) + border-color fire), aspect-ratio 1/1 for image
    - Instagram icon SVG (same as Footer.astro) in top-right corner as subtle brand mark

    **InstagramFeed.astro** — Grid of curated posts:
    - Props: `locale: Locale`, `translations: Record<string, any>`, `maxPosts?: number` (default 6)
    - Fetch curated posts: `fetchCollection<StrapiInstagramPost>('instagram-posts', { filters: { curated: { $eq: true } }, populate: 'cached_image', sort: 'timestamp:desc', pageSize: maxPosts })`
    - NOTE: instagram-posts is NOT localized (i18n localized: false in schema), so do NOT pass locale to fetchCollection. Override by passing locale: 'en' explicitly (Strapi default)
    - Wrap in try/catch with empty array fallback (silent fail if Strapi offline)
    - If no posts, render nothing (return early with empty fragment)
    - Section heading using translation key `social.instagramTitle` ("From Our Instagram" / "Dal Nostro Instagram" / "De Nuestro Instagram")
    - Responsive grid: 2 cols on mobile, 3 cols on tablet (md), 3 cols on desktop
    - "Follow on Instagram" link below grid linking to https://instagram.com/bbqexperience
    - data-animate attribute on section for GSAP scroll trigger
