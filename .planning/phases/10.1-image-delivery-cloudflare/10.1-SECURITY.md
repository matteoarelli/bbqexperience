# Phase 10.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.
> Scope: Cloudflare Image Transformations rollout (orange-cloud flip + Sources allowlist + `/cdn-cgi/image/` URL emission from Astro).

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| client -> Cloudflare edge | Post orange-cloud, tutte le richieste `bbq-experience.com` passano da CF; TLS termina all'edge CF, non a Caddy. | Richieste HTTP pubbliche (read-only asset) |
| CF edge -> `cms.bbq-experience.com` origin | Transformations fetchano l'origine per conto del client `/cdn-cgi/image/...`; Sources allowlist filtra gli origin ammessi. | URL origine + parametri transform |
| Astro SSR render -> HTML response | Campi controllati da CMS (`StrapiMedia.url`) vengono concatenati nel path `/cdn-cgi/image/`; devono essere url-encoded. | Media metadata da Strapi |
| Astro SSR -> OpenGraph scrapers (Facebook/X/LinkedIn/Slack/Discord) | Scrapers possono non seguire `/cdn-cgi/image/` in modo affidabile; `og:image` deve restare raw. | Metadati pubblici (og:image URL) |

Probe negativo su `example.com` → 4xx documentato in `10.1-01-SUMMARY.md` §probe-3. | closed |
| T-10.1-02 | T (Tampering) | Image URL path-parameter injection (Plan 01 scope) | mitigate | Tracked forward to T-10.1-05 (stesso attacco, implementato in Plan 02). Chiusura via encodeURI in `getStrapiMediaURL`. | closed |
| T-10.1-03 | D (Denial of Service) | Cache-miss flood all'edge CF | accept | Volume traffico basso (~500 uniques/day); CF Free plan fornisce bandwidth illimitata. Non blocking per ASVS L1. | closed |
| T-10.1-04 | R (Repudiation) | Modifica config dashboard CF senza audit trail nel repo | mitigate | `10.1-01-SUMMARY.md` registra probe before/after con timestamp e header edge catturati → cambio stato git-attested anche se dashboard CF è opaca. | closed |
| T-10.1-05 | T (Tampering) | Path-parameter injection via `StrapiMedia.url` in `getStrapiMediaURL` | mitigate | `encodeURI(sourceUrl)` applicato prima della concat (`web/src/lib/media.ts:77`). | T-10.1-06 | I (Information Disclosure) | `og:image` leak che espone URL trasformata ai social scraper che la 404-ano | mitigate | Blog `[slug]` pages EN/IT/ES passano `{raw:true}` → `ogImage` emette URL Strapi raw. | T-10.1-07 | D (DoS via cache stampede) | Free-tier cap 5000 unique transforms/mese | accept | Proiezione RESEARCH: 300-800 unique transforms/mese, ampiamente sotto cap. Monitor manuale dashboard CF con alert soglia 4000. | closed |

| T-10.1-09 | I (Information Disclosure) / Performance | Preload URL mismatch con `<img src>` → double-fetch | mitigate | Tutti i preload emessi con stessa `width` dell'`<img>` LCP (1280 hero, 1280 cover). Probe produzione homepage EN: preload href === featured-main src. | closed |
