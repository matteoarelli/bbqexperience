# Phase 10.1 Plan 02: Wire Cloudflare Image Transformations Summary

Shipped Cloudflare Image Transformations + responsive srcset across BBQ Experience via single-helper rewrite (`web/src/lib/media.ts`) and wired 12 hot templates to emit `/cdn-cgi/image/width=W,quality=75,format=auto/<origin>` URLs — closing the residual DEBT-03 performance gap (median Perf 0.89 → 0.97, 15/15 pages ≥90 on mobile Lighthouse).

## Summary

Plan 10.1-01 ha preparato l'infrastruttura lato CF (orange-cloud + Transformations + Sources allowlist). Plan 10.1-02 ha flippato il pipeline di emissione URL del sito per sfruttarla:

1. Riscritto `getStrapiMediaURL(media, opts?)` per accettare `TransformOptions` (width/quality/format/fit/raw). Aggiunto `buildStrapiSrcset(media, widths)` per responsive srcset. Backward compatible: i ~29 call-site esistenti senza opts continuano a ricevere URL raw.
2. Wired 4 surface hot (FeaturedHero, ContentLayout, ReviewCard, preloadImage dei 9 slug/index) per emettere URL trasformate con width matched al rendering + srcset con 3-4 breakpoint responsive.
3. Re-misurato Lighthouse: 15/15 pagine passano ≥90 su tutte le 4 categorie (Performance median 0.97, regression-free). DEBT-03 CLOSED.

Zero nuove dipendenze npm. Italian code comments mantenuti. Deploy via webhook adnanh/webhook (nessun intervento manuale).

### Preload=src match (T-10.1-09)

```
# Homepage EN preload:
<link rel="preload" as="image"
  href="https://bbq-experience.com/cdn-cgi/image/width=1280,quality=75,format=auto/
        https://cms.bbq-experience.com/uploads/stop_buying_cheap_thermometers_...jpg"
  fetchpriority="high">

# Same page featured-main <img>:
<img src="https://bbq-experience.com/cdn-cgi/image/width=1280,quality=75,format=auto/
         https://cms.bbq-experience.com/uploads/stop_buying_cheap_thermometers_...jpg"
  srcset="...width=640 640w, ...width=960 960w, ...width=1280 1280w, ...width=1600 1600w"
  sizes="(max-width: 768px) 100vw, 1280px" ...>
```

**Preload href === `<img src>`**: zero double-fetch, LCP ottimale.

### og:image raw bypass (T-10.1-06)

```
# Blog-en <meta property="og:image">:
<meta property="og:image"
  content="https://cms.bbq-experience.com/uploads/oklahoma_joes_new_offset_smoker_lineup_5eed5de129.jpg">
```

**No `/cdn-cgi/image/` in og:image** — compat social scrapers preservata.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Test bug] srcset entry count splitter**
- **Found during:** Task 1 GREEN phase re-run
- **Issue:** Il test `buildStrapiSrcset` originale usava `result.split(',')` per contare le entry, ma le URL Cloudflare contengono virgole interne (`width=640,quality=75,format=auto`) che facevano fallire il count (atteso 2 entry, ricevuto 6 split).
- **Fix:** Cambiato splitter a `split(', ')` (virgola+spazio) coerente con il separator usato dal helper `join(', ')`.
- **Files modified:** `web/src/lib/media.test.ts`
- **Commit:** incluso in `1b653f2` (Task 1)
