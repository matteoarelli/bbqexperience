    1. In BaseLayout.astro:
       a. Add import: `import ThemeToggle from '@components/common/ThemeToggle.svelte';`
       b. Add an inline `<script is:inline>` tag as the FIRST child inside `<head>`, BEFORE SEOHead. This prevents FOUC (flash of unstyled content). The script:
          ```
          (function(){
            var t = localStorage.getItem('bbq-theme');
            if (t === 'light') document.documentElement.dataset.theme = 'light';
          })();
          ```
          This runs synchronously before any paint. Dark is the default (no attribute needed), light sets data-theme="light".
       c. Place the ThemeToggle island inside the body, after the skip-to-content link and before `<slot name="header" />`. Use a fixed-position wrapper:
          ```astro
          <div class="fixed top-4 right-4 z-50">
            <ThemeToggle client:load label={getTranslation(translations, 'theme.toggle')} />
          </div>
          ```
       d. Add the necessary imports and data for translations. Since BaseLayout does not currently load translations, add:
          - Import `loadTranslations` and `getTranslation` from `@lib/i18n`
          - In frontmatter: `const translations = await loadTranslations(locale as any);`

    2. In global.css, add a `@layer base` rule for smooth theme transition (AFTER the existing base rules):
       ```css
       html[data-theme="light"] {
         color-scheme: light;
       }
       html:not([data-theme="light"]) {
         color-scheme: dark;
       }
       ```
       Do NOT add `transition: background-color` to html — it causes flash on page load. The tokens swap is instant.

    3. Also in global.css, update the `::selection` and `a:hover` rules to use CSS variables (they already do, just verify they work with light theme). Add `prose-invert` handling: in light mode, prose content should NOT be inverted. Add:

       }
