## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query params -> Strapi API | User-controlled brand/category/score/price values reach Strapi filter queries |
| URL query params -> HTML output | Filter values appear in filter pill labels and URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-03 | Tampering | Reviews index query params | mitigate | parseFilterParams whitelist-validates score and price values; brand/category are Strapi slug lookups (no injection risk — Strapi returns empty results for non-existent slugs) |
| T-13-04 | Spoofing | ReviewFilterDrawer URL navigation | mitigate | buildFilterUrl uses URLSearchParams constructor which auto-encodes values; no raw string concatenation |
| T-13-05 | Denial of Service | Double fetch (all reviews + filtered) | accept | 25-item corpus; all-reviews fetch is ~2KB; Strapi rate-limits are not needed at this scale |
</threat_model>
