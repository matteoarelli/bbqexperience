## Component Inventory

### 1. NewsletterSignup.astro (MODIFY existing)

**Changes from current:**
- New prop: `source: 'inline' | 'landing' | 'footer' | 'exit-intent'` (default `'inline'`)
- New hidden honeypot field: `<input name="website" type="text" tabindex="-1" autocomplete="off" aria-hidden="true" class="newsletter__honeypot" />` styled with `position: absolute; left: -9999px; opacity: 0; height: 0; width: 0;`
- New state: "confirm" — replaces success text with DOI confirmation message
- New data attribute: `data-newsletter-source="{source}"` on container, read by script for POST body

**States:**
| State | Visual |
|-------|--------|
| Idle | Form visible (input + button). No header in compact mode. |
| Submitting | Button text changes to a loading indicator (CSS spinner, 16x16px, white). Button disabled. |
| Confirm (DOI) | Form hidden. Green checkmark SVG (20x20) + confirm message text in `--color-accent-fire`. |
| Error | Inline error text below input in `--color-negative`, font-size `--text-sm`. Form remains editable. |
| Already subscribed | Form hidden. Success text shown (existing localStorage check). |

### 2. ExitIntentModal.astro (NEW)

**Layout:** Full-viewport overlay with centered card.
- Overlay: `position: fixed; inset: 0; z-index: 100; background: rgba(0, 0, 0, 0.6); display: flex; align-items: center; justify-content: center;`
- Card: `max-width: 480px; width: calc(100% - 32px); background: var(--color-bg-secondary); border-radius: var(--radius-lg); overflow: hidden;`
- Card top border: 4px solid fire gradient (`linear-gradient(90deg, var(--color-accent-fire), var(--color-accent-ember), var(--color-accent-fire))`)
- Close button: top-right corner of card, 40x40px touch target, "X" icon in `--color-text-muted`, hover `--color-text-primary`
- Content: newsletter title + subtitle + NewsletterSignup (full mode, `source="exit-intent"`)
- Card padding: `var(--space-8)` all sides, `var(--space-6)` on mobile (<640px)

**Accessibility (D-06):**
- `role="dialog"` + `aria-modal="true"` + `aria-label` from i18n key
- Focus trap: tab cycles through email input, submit button, close button
- `aria-live="polite"` region announces modal open
- Close on Escape key press
- Close on overlay click (outside card)
- Return focus to previously focused element on close

**Animation (GSAP):**
- Entry: overlay `opacity: 0 -> 1` (300ms, `power2.out`), card `scale: 0.9 -> 1, opacity: 0 -> 1` (400ms, `back.out(1.4)`, 100ms delay)
- Exit: card `scale: 1 -> 0.95, opacity: 1 -> 0` (200ms, `power2.in`), overlay `opacity: 1 -> 0` (250ms, `power2.in`, 50ms delay)

**Trigger (D-05, D-07, D-09):**
- Only on `(hover: hover) and (pointer: fine)` devices
- `mouseleave` on `document.documentElement` with `clientY < 0` guard
- Suppressed if: `bbq-exit-modal-dismissed` cookie exists (14-day), OR `bbq-exit-modal-shown` sessionStorage flag, OR `bbq-newsletter-subscribed` localStorage
- On show: set `bbq-exit-modal-shown` in sessionStorage
- On dismiss (X or overlay click or Escape): set `bbq-exit-modal-dismissed` cookie (14 days)

### 3. StickyNewsletterBar.astro (NEW)

**Layout:** Fixed bar at viewport bottom.
- Container: `position: fixed; bottom: 0; left: 0; right: 0; z-index: 90; background: var(--color-bg-secondary); border-top: 1px solid var(--color-border-default); padding: var(--space-3) var(--space-4);`
- Height: 56px (auto-height, min 56px)
- Inner layout: `display: flex; align-items: center; gap: var(--space-3); max-width: var(--container-max); margin: 0 auto;`
- Left: short CTA text (1 line, `--text-sm`, `--color-text-secondary`, hidden on <480px viewports to save space)
- Center: email input (flex: 1, same styling as NewsletterSignup input)
- Right: submit button (compact, same styling as NewsletterSignup button)
- Far right: dismiss "X" button (32x32px touch target, `--color-text-muted`)
- Source: `"footer"` per D-14

**States:**
| State | Visual |
|-------|--------|
| Hidden | `transform: translateY(100%)` — off-screen below |
| Visible | `transform: translateY(0)` — slides up |
| Confirm | Input + button replaced by confirm message text (single line) |
| Dismissed | Slides down, then `display: none` |

**Animation (GSAP, D-11):**
- Entry: `translateY(100%) -> translateY(0)` (500ms, `power3.out`)
- Trigger: after 5 seconds OR 30% scroll depth, whichever comes first
- Exit (dismiss): `translateY(0) -> translateY(100%)` (300ms, `power2.in`)

**Suppression (D-12, D-13):**
- Hidden if: `bbq-sticky-bar-dismissed` cookie (30-day), OR `bbq-newsletter-subscribed` localStorage
- Hidden when footer is visible: IntersectionObserver on `<footer>` with threshold 0; hide bar when intersecting, show when not
- On dismiss: set `bbq-sticky-bar-dismissed` cookie (30 days)
- On successful subscribe: set `bbq-newsletter-subscribed` in localStorage, hide bar

### 4. Newsletter Landing Pages (NEW — 3 locale pages)

**URL:** `/en/newsletter/`, `/it/newsletter/`, `/es/newsletter/`

**Layout sections (top to bottom):**

1. **Hero** — `padding: var(--space-16) var(--space-4);` centered text
   - Heading: `--text-3xl`, Oswald, weight 700, uppercase, `--color-text-primary`
   - Subtitle: `--text-base`, Inter, weight 400, `--color-text-secondary`, max-width 640px, line-height 1.5
   - Spacing between heading and subtitle: `var(--space-4)`

2. **Benefits grid** — 3-column on desktop (>=768px), 1-column on mobile
   - Container: `padding: var(--space-12) var(--space-4); background: var(--color-bg-secondary);`
   - Grid: `display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: var(--space-6);`
   - Each card: `padding: var(--space-6); text-align: center;`
     - Icon: inline SVG, 48x48px, `--color-accent-fire` fill (flame icon for reviews, chef-hat for recipes, lock for secrets)
     - Title: `--text-base`, Oswald, weight 700, uppercase, `--color-text-primary`, margin-top `var(--space-3)`
     - Description: `--text-sm`, Inter, weight 400, `--color-text-muted`, line-height 1.5, margin-top `var(--space-2)`

3. **Social proof** — single centered line
   - `padding: var(--space-8) var(--space-4);`
   - Text: `--text-2xl`, Inter, weight 700, `--color-text-secondary`
   - Number "74,000+": `--color-accent-fire`, weight 700

4. **Signup form** — centered, max-width 560px
   - `padding: var(--space-12) var(--space-4);`
   - Uses `<NewsletterSignup translations={translations} source="landing" />`

5. **Consent text** — below form
   - `--text-sm`, Inter, weight 400, `--color-text-muted`, line-height 1.5, max-width 480px, centered
   - Contains link to privacy policy: `--color-accent-fire`, underline on hover

**SEO (D-19):**
- Each page: `<title>`, `<meta name="description">`, hreflang to sibling locales
- No JSON-LD (not a schema.org type)

### Empty State

Not applicable -- newsletter forms are always visible (no "empty data" scenario). Already-subscribed users see the existing success message.

### Error States

| Condition | HTTP Status | User sees |
|-----------|-------------|-----------|
| Invalid email (client-side) | n/a | `newsletter.errorInvalidEmail` below input, `--color-negative` |
| Rate limited | 429 | `newsletter.errorRateLimit` below input, `--color-negative` |
| Server/network error | 5xx / timeout | `newsletter.errorGeneric` below input, `--color-negative` |
| Honeypot triggered | 403 | Silent fail — form shows generic error to avoid bot fingerprinting |

### Destructive Actions

None in this phase. Newsletter signup is additive. No unsubscribe UI is in scope (handled by Brevo email footer).

## Interaction Contracts

### Inline Form (all article pages)

| Interaction | Behavior |
|-------------|----------|
| Form submit | POST to `/api/newsletter` with `{ email, locale, source: "inline" }` |
| Success | Hide form, show DOI confirm message with green checkmark |
| Error | Show inline error below input, form remains editable |
| Subsequent page load (subscribed) | Form hidden, success text shown via localStorage check |

### Exit-Intent Modal

| Interaction | Behavior |
|-------------|----------|
| Mouse exits top of viewport | Show modal (if not suppressed) |
| Click "X" or overlay | Close modal, set 14-day dismiss cookie |
| Press Escape | Close modal, set 14-day dismiss cookie |
| Submit form | POST with `source: "exit-intent"`, show confirm state inside modal |
| Tab key | Cycles: email input -> submit -> close button -> email input |

### Sticky Footer Bar

| Interaction | Behavior |
|-------------|----------|
| 5s elapsed OR 30% scroll | Slide bar up from bottom |
| Submit email | POST with `source: "footer"`, show confirm text inline |
| Click "X" | Slide bar down, set 30-day dismiss cookie |
| Scroll to footer | Hide bar (IntersectionObserver) |
| Scroll away from footer | Show bar again (if not dismissed) |

### Landing Page

| Interaction | Behavior |
|-------------|----------|
| Page load | Full page with hero, benefits, social proof, form |
| Submit email | POST with `source: "landing"`, show confirm state |
| Privacy link click | Navigate to `/{locale}/privacy/` |
