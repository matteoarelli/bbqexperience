<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent -> Umami API | Credentials sent over HTTPS to self-hosted analytics |
| Agent -> Strapi API | API token sent over HTTPS to self-hosted CMS |
| Umami response -> Agent | Untrusted JSON parsed and used for Strapi writes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Information Disclosure | umami_client.py | mitigate | Credentials via env vars only (UMAMI_PASSWORD, STRAPI_API_TOKEN), never in code. .env.windows gitignored. |
| T-15-02 | Tampering | umami_feedback.py | mitigate | Validate Umami response: check each item has "x" (str) and "y" (int) keys before processing. Skip malformed entries. |
| T-15-03 | Denial of Service | umami_client.py | accept | Self-hosted Umami on same server. Single nightly cron, 2-4 API calls total. No external DoS vector. |
| T-15-04 | Spoofing | umami_client.py token cache | mitigate | Token cached in-memory only (module-level var), never persisted to disk. 58-min TTL < 60-min expiry. |
</threat_model>
