```python
def update(content_type: str, document_id: str, data: dict, *, locale: str = "") -> dict:
    params = {}
    if locale:
        params["locale"] = locale
    qs = f"?{urlencode(params)}" if params else ""
    url = f"{STRAPI_URL}/api/{content_type}/{document_id}{qs}"
    return _request("PUT", url, {"data": data})
```

The script must:

**Step 1 — Seed product categories (per D-02, D-03):**
Create 5 categories via POST /api/product-categories with EN data, then PUT locale translations for IT and ES.

Category data:
| slug | EN name | IT name | ES name |
|------|---------|---------|---------|
| grill | Grill | Griglia | Parrilla |
| smoker | Smoker | Affumicatore | Ahumador |
| pellet | Pellet Grill | Griglia a Pellet | Parrilla de Pellet |
| thermometer | Thermometer | Termometro | Termometro |
| accessory | Accessory | Accessorio | Accesorio |

For each category:
1. POST /api/product-categories with `{ data: { name: enName, slug: slug, description: "" } }`
2. Capture the returned `documentId`
3. PUT /api/product-categories/{documentId}?locale=it with `{ data: { name: itName, slug: slug, description: "" } }`
4. PUT /api/product-categories/{documentId}?locale=es with `{ data: { name: esName, slug: slug, description: "" } }`

**Step 2 — Backfill products with category relation (per D-01, D-03, FILT-08):**
1. GET /api/product-categories?locale=en&pagination[pageSize]=100 — build a slug→documentId map
2. GET /api/products?locale=en&pagination[pageSize]=100&status=draft — fetch ALL products (draft status gets both published and draft in Strapi v5)
3. For each product, determine the correct category:
   - Old `category` enum values map: grill→grill, smoker→smoker, thermometer→thermometer, fuel→accessory, other→accessory
   - The `pellet` category: products whose name contains "pellet" (case-insensitive) AND were previously grill → pellet
   - If product has no old category value or is unknown → accessory
4. PUT /api/products/{documentId} with `{ data: { product_category: categoryDocumentId } }`

Note: Since the old `category` enum field has been removed from the schema, the migration must read the old values from the database directly. Use a preliminary SQL query via Strapi's internal API or fetch the products BEFORE the schema change. **Alternative approach (recommended):** Hard-code the known product-to-category mapping based on current production data. Since there are only 25 products, this is more reliable than trying to read a removed field. The executor should SSH to Hetzner and query: `docker exec postgres psql -U strapi -d strapi -c "SELECT id, name, category FROM products WHERE category IS NOT NULL;"` to get the mapping, then hard-code it in the script.

**Step 3 — Tag existing subscribers as legacy (per D-07):**
1. GET /api/subscribers?pagination[pageSize]=100 — fetch all subscribers
2. For each subscriber where `source` is null/undefined:
   PUT /api/subscribers/{documentId} with `{ data: { source: "legacy" } }`

**Error handling:**
- Each step prints progress: `[SEED] Created category: grill (documentId: xxx)`
- Each step has try/catch with clear error messages
- Use `AbortSignal.timeout(10_000)` on every fetch (per CLAUDE.md convention)
- Script exits with code 1 if any critical step fails (seeding or product backfill)
- Subscriber tagging failures are logged but don't abort (non-critical)

**Idempotency:**
- Before seeding, check if categories already exist via GET /api/product-categories?filters[slug][$eq]=grill — skip if found
- Before backfilling products, check if product_category is already set — skip if non-null

```typescript
/**

 * Pattern: PUT /api/{contentType}/{documentId}?locale=xx
 * con slug sempre incluso nel body (convenzione CLAUDE.md).
 */

interface UpdateLocalizedOptions {
  /** Tipo di contenuto Strapi (es. "recipe-collections") */
  contentType: string;
  /** Document ID dell'entry da aggiornare */
  documentId: string;
  /** Locale target (es. "it", "es") */
  locale: string;
  /** Dati da aggiornare — DEVE contenere "slug" */
  data: Record<string, unknown> & { slug: string };
}

interface StrapiResponse<T = Record<string, unknown>> {
  data: T;
  meta?: Record<string, unknown>;
}

export async function updateLocalized(
  options: UpdateLocalizedOptions,
  config?: { baseUrl?: string; token?: string }
): Promise<StrapiResponse> {
  // Implementazione con:
  // - baseUrl da config o process.env.STRAPI_URL o default "http://localhost:1337"
  // - token da config o process.env.STRAPI_API_TOKEN
  // - PUT a {baseUrl}/api/{contentType}/{documentId}?locale={locale}
  // - body: { data: options.data } (che include slug)
  // - signal: AbortSignal.timeout(10_000) per timeout
  // - Throw su risposte non-ok con status e body
}
```

The function must:
1. Build URL: `${baseUrl}/api/${contentType}/${documentId}?locale=${locale}`

4. Use `signal: AbortSignal.timeout(10_000)` (CLAUDE.md convention)
5. Check response.ok, throw descriptive error if not
6. Return parsed JSON response
