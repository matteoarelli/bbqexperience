  <action>
Create `web/src/lib/types.ts` with TypeScript interfaces that mirror every Strapi content type schema exactly. This file is the single source of truth for content shapes on the frontend.

Include these interfaces:

1. **StrapiMedia** — Strapi's media object shape: `{ id, name, url, alternativeText, width, height, formats: { thumbnail, small, medium, large } }`. Each format has `{ url, width, height }`.

2. **StrapiResponse<T>** — Wraps single entity: `{ data: T & { id: number, documentId: string, createdAt: string, updatedAt: string, publishedAt: string | null, locale: string } }`. Note: Strapi 5 uses `documentId` (string UUID) as the primary identifier, not numeric `id`.

3. **StrapiCollectionResponse<T>** — Wraps collection: `{ data: Array<T & StrapiEntity>, meta: { pagination: { page, pageSize, pageCount, total } } }`.

4. **StrapiEntity** — Base fields: `{ id: number, documentId: string, createdAt: string, updatedAt: string, publishedAt: string | null, locale: string }`.

5. **StrapiProduct** — Fields from product schema.json: name (string), slug (string), brand (string | null), category (enum: grill|smoker|accessory|fuel|thermometer|other | null), price_range (enum: budget|mid-range|premium|luxury | null), description (string | null), specifications (Record<string, unknown> | null), images (StrapiMedia[] | null), affiliate_url (string | null).

6. **StrapiReview** — Fields from review schema.json: title (string), slug (string), excerpt (string | null), editorial_content (string | null), verdict (string | null), score_overall (number), score_build_quality (number | null), score_performance (number | null), score_value (number | null), score_ease_of_use (number | null), pros (string[] | null), cons (string[] | null), product (StrapiProduct & StrapiEntity | null), gallery (StrapiMedia[] | null), seo_title (string | null), seo_description (string | null), published_date (string | null).

7. **StrapiRecipe** — Fields from recipe schema.json: title, slug, excerpt, editorial_intro (string | null), ingredients (Array<{name: string, quantity: string, unit: string}> | null), instructions (Array<{step: number, text: string, image?: StrapiMedia}> | null), prep_time (number | null), cook_time (number | null), total_time (number | null), servings (number | null), difficulty (enum), meat_type (enum), technique (enum), cover_image (StrapiMedia | null), gallery (StrapiMedia[] | null), seo_title, seo_description, published_date.

8. **StrapiTutorial** — Fields from tutorial schema.json: title, slug, excerpt, content (string | null), category (enum: technique|equipment|knowledge|safety | null), difficulty (enum: beginner|intermediate|advanced | null), reading_time (number | null), cover_image (StrapiMedia | null), seo_title, seo_description, published_date.

9. **StrapiBlogPost** — Fields from blog-post schema.json: title, slug, excerpt, content (string | null), category (enum: news|events|trends|tips|culture | null), reading_time (number | null), cover_image (StrapiMedia | null), featured (boolean), seo_title, seo_description, published_date.

10. **StrapiInstagramPost** — Fields from instagram-post schema.json (non-localized): ig_id (string), permalink (string | null), media_url (string | null), caption (string | null), media_type (enum: image|video|carousel | null), timestamp (string | null), cached_image (StrapiMedia | null), curated (boolean).

Export all interfaces. Use `export interface` (not `export type`) for all content types. Import `Locale` from `./i18n.ts` and export a `ContentType` union type: `'reviews' | 'recipes' | 'tutorials' | 'blog-posts' | 'products' | 'instagram-posts'`.

**Create `web/src/lib/strapi.ts`** — the Strapi REST API client used by all Astro pages at build time.

Read `STRAPI_URL` and `STRAPI_API_TOKEN` from `import.meta.env`. Export a constant `STRAPI_URL` so media.ts can import it.

Functions to implement:

1. `fetchAPI<T>(endpoint: string, params?: Record<string, string>): Promise<T>` — Base fetch wrapper. Sends GET to `${STRAPI_URL}/api/${endpoint}?${params}` with `Authorization: Bearer ${STRAPI_API_TOKEN}` header. Throws descriptive error on non-OK response including status code and endpoint. Returns parsed JSON.

2. `fetchCollection<T>(contentType: ContentType, options: { locale?: Locale, page?: number, pageSize?: number, populate?: string | string[], filters?: Record<string, unknown>, sort?: string | string[], status?: 'published' | 'draft' }): Promise<StrapiCollectionResponse<T>>` — Builds query params from options. For `populate`, if string use as-is, if array join with comma. For `filters`, serialize as Strapi v5 filter syntax (e.g., `filters[field][$eq]=value`). For `status`, pass as `status` param (Strapi 5 uses `status` not `publicationState`). Default locale to `'en'`. Default pageSize to 25. Default status to `'published'`.

3. `fetchOne<T>(contentType: ContentType, documentId: string, options: { locale?: Locale, populate?: string | string[], status?: 'published' | 'draft' }): Promise<StrapiResponse<T>>` — Fetches single entry by documentId. NOTE: Strapi 5 uses `GET /api/{contentType}/{documentId}` (not numeric id). Default status to `'published'`.

4. `fetchBySlug<T>(contentType: ContentType, slug: string, options: { locale?: Locale, populate?: string | string[], status?: 'published' | 'draft' }): Promise<(T & StrapiEntity) | null>` — Convenience: calls fetchCollection with `filters[slug][$eq]=slug` and `pagination[pageSize]=1`, returns first result or null.

Import types from `./types.ts`. Import `Locale`, `defaultLocale` from `./i18n.ts`.

**Create `web/src/lib/media.ts`** — helpers for resolving Strapi media URLs.

1. `getStrapiMediaURL(media: StrapiMedia | null | undefined): string | null` — If media is null/undefined return null. If media.url starts with 'http' return as-is. Otherwise prepend STRAPI_URL (imported from strapi.ts). This handles both local dev (relative URLs) and production (absolute URLs from Strapi).

2. `getStrapiImageFormats(media: StrapiMedia | null | undefined): { thumbnail?: string, small?: string, medium?: string, large?: string }` — Returns absolute URLs for each available format. Uses same URL resolution logic.

3. `getStrapiMediaAlt(media: StrapiMedia | null | undefined): string` — Returns `media.alternativeText` or empty string as fallback.

Import `StrapiMedia` from `./types.ts` and `STRAPI_URL` from `./strapi.ts`.

Also update `web/.env.example` (create if not exists) with:
```
STRAPI_URL=http://localhost:1337
STRAPI_API_TOKEN=change-me
```
