  <action>
    Create a complete Strapi 5 CMS project from scratch (do NOT use `npx create-strapi` — create files manually for full control).

    **1. package.json:** Create with `@strapi/strapi` version `5.40.0` and all required Strapi dependencies for v5:
    - `@strapi/strapi`: `5.40.0`
    - `@strapi/plugin-cloud`: `5.40.0`
    - `@strapi/plugin-users-permissions`: `5.40.0`
    - `@strapi/plugin-i18n`: `5.40.0`
    - `pg`: `^8.13.0` (PostgreSQL client)
    - `better-sqlite3`: `11.8.1` (for local development)
    - Scripts: `develop` (`strapi develop`), `start` (`strapi start`), `build` (`strapi build`), `strapi` (`strapi`)
    - Set `type: "commonjs"` (Strapi 5 requires CommonJS)

    **2. tsconfig.json:** Standard Strapi 5 TypeScript config extending `@strapi/typescript-utils/tsconfigs/server`.

    **3. Configuration files (cms/config/):**

    - **database.ts:** Use `env()` helper. For production (NODE_ENV=production): use `DATABASE_CLIENT=postgres`, `DATABASE_HOST`, `DATABASE_PORT=5432`, `DATABASE_NAME`, `DATABASE_USERNAME`, `DATABASE_PASSWORD` from env vars. For development: use `better-sqlite3` with file at `.tmp/data.db`. This dual config lets local dev work without PostgreSQL.

    - **server.ts:** Set `host: env('HOST', '0.0.0.0')`, `port: env.int('PORT', 1337)`, `url: env('PUBLIC_URL', 'http://localhost:1337')`. Configure `app.keys` from `env.array('APP_KEYS')`. Add `webhooks.defaultHeaders` with `'X-Rebuild-Secret': env('REBUILD_SECRET_TOKEN', '')` — this is the secret header Strapi sends on content change webhooks.

    - **plugins.ts:** Enable i18n plugin with `defaultLocale: 'en'`. No other plugin config needed (i18n is built-in in Strapi 5).

    - **middlewares.ts:** Standard Strapi 5 middleware stack: `strapi::logger`, `strapi::errors`, `strapi::security`, `strapi::cors`, `strapi::poweredBy`, `strapi::query`, `strapi::body`, `strapi::session`, `strapi::favicon`, `strapi::public`.

    - **admin.ts:** Standard admin config with `auth.secret` from `env('ADMIN_JWT_SECRET')`.

    **4. Content type schemas** — Create all 6 content types. Each needs schema.json + routes/controllers/services TS files (standard Strapi boilerplate using `createCoreRouter`, `createCoreController`, `createCoreService` from `@strapi/strapi/factories`).

    **Product** (cms/src/api/product/content-types/product/schema.json):
    - kind: `collectionType`, collectionName: `products`, displayName: `Product`
    - draftAndPublish: true, i18n.localized: true
    - Attributes: `name` (string, required, localized), `slug` (uid, targetField: name), `brand` (string, NOT localized — brand name is universal), `category` (enumeration: grill, smoker, accessory, fuel, thermometer, other), `price_range` (enumeration: budget, mid-range, premium, luxury), `description` (richtext, localized), `specifications` (json — flexible key/value for specs), `images` (media, multiple, images only), `affiliate_url` (string — for future v2 monetization, optional)

    **Review** (cms/src/api/review/content-types/review/schema.json):
    - kind: `collectionType`, collectionName: `reviews`, displayName: `Review`
    - draftAndPublish: true, i18n.localized: true
    - Attributes: `title` (string, required, localized), `slug` (uid, targetField: title), `excerpt` (text, localized — short summary for cards), `editorial_content` (richtext, localized — the deep-dive opinion), `verdict` (text, localized — one-line verdict summary), `score_overall` (decimal, required — 0-10), `score_build_quality` (decimal — 0-10), `score_performance` (decimal — 0-10), `score_value` (decimal — 0-10), `score_ease_of_use` (decimal — 0-10), `pros` (json — array of strings, localized), `cons` (json — array of strings, localized), `product` (relation: manyToOne with Product), `gallery` (media, multiple, images only), `seo_title` (string, localized), `seo_description` (text, localized), `published_date` (date)

    **Recipe** (cms/src/api/recipe/content-types/recipe/schema.json):
    - kind: `collectionType`, collectionName: `recipes`, displayName: `Recipe`
    - draftAndPublish: true, i18n.localized: true
    - Attributes: `title` (string, required, localized), `slug` (uid, targetField: title), `excerpt` (text, localized), `editorial_intro` (richtext, localized — the intro before "Jump to Recipe"), `ingredients` (json, localized — array of {name, quantity, unit}), `instructions` (json, localized — array of {step, text, image_url}), `prep_time` (integer — minutes), `cook_time` (integer — minutes), `total_time` (integer — minutes), `servings` (integer), `difficulty` (enumeration: easy, medium, hard, expert), `meat_type` (enumeration: beef, pork, chicken, lamb, fish, vegetarian, mixed), `technique` (enumeration: grilling, smoking, roasting, braising, other), `cover_image` (media, single, images only), `gallery` (media, multiple, images only), `seo_title` (string, localized), `seo_description` (text, localized), `published_date` (date)

    **Tutorial** (cms/src/api/tutorial/content-types/tutorial/schema.json):
    - kind: `collectionType`, collectionName: `tutorials`, displayName: `Tutorial`
    - draftAndPublish: true, i18n.localized: true
    - Attributes: `title` (string, required, localized), `slug` (uid, targetField: title), `excerpt` (text, localized), `content` (richtext, localized — the full tutorial body), `category` (enumeration: technique, equipment, knowledge, safety), `difficulty` (enumeration: beginner, intermediate, advanced), `reading_time` (integer — estimated minutes), `cover_image` (media, single, images only), `seo_title` (string, localized), `seo_description` (text, localized), `published_date` (date)

    **BlogPost** (cms/src/api/blog-post/content-types/blog-post/schema.json):
    - kind: `collectionType`, collectionName: `blog_posts`, displayName: `BlogPost`
    - draftAndPublish: true, i18n.localized: true
    - Attributes: `title` (string, required, localized), `slug` (uid, targetField: title), `excerpt` (text, localized), `content` (richtext, localized), `category` (enumeration: news, events, trends, tips, culture), `reading_time` (integer), `cover_image` (media, single, images only), `featured` (boolean, default false — for homepage hero), `seo_title` (string, localized), `seo_description` (text, localized), `published_date` (date)

    **InstagramPost** (cms/src/api/instagram-post/content-types/instagram-post/schema.json):
    - kind: `collectionType`, collectionName: `instagram_posts`, displayName: `InstagramPost`
    - draftAndPublish: true, i18n.localized: false (IG posts are language-agnostic in the cache)
    - Attributes: `instagram_id` (string, required, unique), `media_type` (enumeration: IMAGE, VIDEO, CAROUSEL_ALBUM), `media_url` (string), `thumbnail_url` (string — for VIDEO type), `permalink` (string), `caption` (text), `timestamp` (datetime), `cached_image` (media, single, images only — locally cached copy), `curated` (boolean, default false — for featured display on site)

    **5. .env.example:** Template with all required env vars:
    ```
    HOST=0.0.0.0
    PORT=1337
    PUBLIC_URL=http://localhost:1337
    APP_KEYS=key1,key2,key3,key4
    JWT_SECRET=your-jwt-secret
    ADMIN_JWT_SECRET=your-admin-jwt-secret
    API_TOKEN_SALT=your-api-token-salt
    TRANSFER_TOKEN_SALT=your-transfer-token-salt
    DATABASE_CLIENT=better-sqlite3
    DATABASE_FILENAME=.tmp/data.db
    REBUILD_SECRET_TOKEN=your-rebuild-secret
    ```

    **6. Dockerfile:** Multi-stage production build as specified in research. Stage 1 (build): node:22-alpine, install system deps (build-base, vips-dev), npm ci, npm run build. Stage 2 (production): node:22-alpine, copy node_modules and built app, run as `node` user, expose 1337, CMD npm run start.

    **7. .dockerignore:** Exclude node_modules, .tmp, .cache, .env, build, dist, .git.

    **8. src/admin/app.example.ts:** Empty Strapi admin customization placeholder.
